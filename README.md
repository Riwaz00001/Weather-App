# Weather-App
A modern, desktop weather application built with Python. It fetches real-time weather data via a REST API and displays it inside a  GUI.

## Features

* **Real-Time Weather:** Displays current temperature, weather conditions, and humidity.
* **Modern UI:** Built using `CustomTkinter` for a dark/light-mode ready interface.
* **Dynamic Icons:** Loads custom weather condition icons using `Pillow`.
* **City Search:** search weather conditions for any city worldwide.

## Tech Stack

* **Language:** Python
* **GUI Framework:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
* **Image Processing:** [Pillow (PIL)](https://python-pillow.org/)
* **HTTP Client:** [Requests](https://requests.readthedocs.io/)
